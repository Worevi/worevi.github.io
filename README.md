> A versão pública da página de entrega da padaria À Antiga, publicada em GitHub Pages.

---

## O que é

Página única e estática, sem dependências, onde o cliente vê e descarrega o
material final. As miniaturas e pré-visualizações são comprimidas só para a
página abrir depressa — os ficheiros que se descarregam são os originais.

## Estrutura

```
index.html     a página
preview/       pré-visualizações leves dos vídeos
thumbs/        miniaturas das fotografias
```
